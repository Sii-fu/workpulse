# WorkPulse v2 Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the four per-theme layouts with one layout (Today, Tasks, History, Settings) dressed by three themes (The Chase, Time Card, Graphite Console), and add the office clock and the End my day flow.

**Architecture:** Pure helpers first (workday maths, timer segments and overs, next action, week totals, exports), each unit-tested. Then new presentational components under `src/components/v2/`, which compile but are not mounted. Then one swap task rewires `App.tsx`, migrates the theme ids and deletes the old UI. `App.tsx` keeps owning all state and handlers.

**Tech Stack:** React 19, TypeScript, Tailwind v4 + CSS variables, lucide-react, Vitest, Python Playwright smoke test.

**Spec:** `docs/superpowers/specs/2026-11-10-redesign-v2-design.md` (read it first). The visual reference is the approved sketches
`.impeccable/mocks/decision/assigned.html` (Chase), `model-pick.html` (Time Card) and `challenger-console.html` (Console), plus the direction
contract in `.impeccable/surfaces/src-app-tsx.md`.

## Global Constraints

- No new npm dependencies. Fonts come from Google Fonts via `index.html`, with `Noto Sans Bengali` kept as a fallback in every stack.
- Dates are local: use `localDateStr()`, `localTimeStr()` and `localDateOfIso()` from `src/utils/dates.ts`. Never `toISOString().split('T')[0]`. Tests that touch dates set `process.env.TZ = 'Asia/Dhaka'`.
- Durations only come from tracked time (`minutesFromSeconds`). Activity estimates stay labelled "estimated".
- Running clocks render through `timerStore` (`liveSecondsOf` / `<TaskClock>`), never `task.elapsedSeconds` in JSX. Screens given `backlog` are `React.memo` with `sameTasksIgnoringLiveTime`, and handlers go through `useStableCallback`.
- Three type sizes per theme: `--fs-body` 15px, `--fs-small` 13px (never below 12px, no `text-[10px]`), and numerals `--fs-num` (64px desktop band, 40px Time Card cells, 15px Console). Rank comes from weight, case and colour.
- WCAG 2.2 AA in every theme. Icon-only buttons use `IconButton` with a `label`. Dialogs use `ModalShell`. Targets are 24px minimum, 44px under 640px. Respect `prefers-reduced-motion`.
- No gradients, glass, glow, drop shadows on cards, nested cards, or icon tiles. Surfaces are flat, with 1px lines.
- Copy uses plain sentences, and failures go through `plainAiMessage` / `plainSheetMessage`.
- The Sheet columns and Apps Script are unchanged.
- The theme tokens keep the existing variable names (`--bg-app`, `--bg-surface`, `--bg-surface-elevated`, `--bg-subtle`, `--bg-subtle-hover`, `--border-app`, `--border-control`, `--border-focus`, `--text-main`, `--text-muted`, `--text-subtle`, `--accent`, `--accent-hover`, `--accent-text`, `--on-accent`, `--radius-card`, `--radius-btn`, `--font-display`, `--font-body`, `--font-mono`, status colours) so kept components restyle for free. New tokens are `--band-bg`, `--band-ink`, `--band-muted`, `--band-line`, `--clock-calm`, `--clock-near`, `--clock-due`, `--clock-over`, `--font-num`, `--num-stretch`, `--fs-body`, `--fs-small`, `--fs-num`, `--row-pad`.
- Commit after every task, ending the message with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Clocked in yesterday, app opened today.** The band shows "Clocked in since Mon 09:48" with Clock out and Clock in for today. No crash, and nothing auto-closed (Task 1 test `openWorkdayBefore`).
2. **Existing users with `theme: 'matrix'` / `'minimalist'` / `'modern'` / `'compact'` or unknown values** land on console / timecard / chase / chase / chase, both in `index.html` pre-paint and in `loadStoredData` (Task 4 tests).
3. **Old tasks with no `segments`, and a timer running at load.** The overs strip shows empty balls, not an error. A task running when the page loads gets an open segment so the strip is not empty (Task 2 test `ensureOpenSegment`).
4. **Backup import of an old file with no `workdays`.** Import succeeds and current workdays are kept (Task 1 test).
5. **Clock out with a running timer.** The warning lists the running task and offers "Pause and clock out". Clocking out never stops tracked time silently (Task 10 step).

### Task 1: Workday model, storage and backup

**Interfaces:**
- Produces (types.ts): `interface WorkdayRecord { clockIn: string; clockOut?: string }` (ISO strings). `type Workdays = Record<string, WorkdayRecord>` (keyed by local `YYYY-MM-DD` of clockIn).
- Produces (workday.ts):
  - `DEFAULT_WORKDAY_HOURS = 8`
  - `type ClockPhase = 'off' | 'calm' | 'near' | 'due' | 'over' | 'out'`
  - `interface ClockState { phase: ClockPhase; workedSec: number; leftSec: number; overSec: number; leaveAtMs: number | null; clockInMs: number | null }`
  - `clockState(rec: WorkdayRecord | undefined, hours: number, nowMs: number): ClockState`. `off` means no record. `out` means clockOut is set (workedSec = out − in). Otherwise: leftSec > 3600 → calm, 900 < leftSec ≤ 3600 → near, 0 < leftSec ≤ 900 → due, leftSec ≤ 0 → over (overSec = now − leaveAt).
  - `openWorkdayBefore(workdays: Workdays, today: string): { date: string; rec: WorkdayRecord } | null` returns the latest earlier date with no clockOut.
  - `clockIn(workdays: Workdays, atIso: string): Workdays` keys the record by `localDateOfIso(atIso)` and keeps an existing record for that date unchanged.
  - `clockOut(workdays: Workdays, date: string, atIso: string): Workdays`
  - `resumeWorkday(workdays: Workdays, date: string): Workdays` removes clockOut.
  - `formatHm(sec: number): string` → `"5:38"` (h:mm, no leading zero on hours). Negative is treated as 0.
  - `isWorkdays(v: unknown): v is Workdays` is a guard for storage and backup.
- Produces (storage.ts): `saveWorkdays(w: Workdays): SaveResult`. `loadStoredData()` also returns `workdays: Workdays` (absent → `{}`, corrupt → quarantined like other keys, `{}`).

**Interfaces:**

A slot's project is the one whose segments overlap it the longest (open segments end at now). The slot containing now is `now` (it wins over project). Slots after now are empty. Unknown project → color `#8a8f98`, name `'Unassigned'`.
